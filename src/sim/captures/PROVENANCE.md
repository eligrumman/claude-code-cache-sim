# Simulation data provenance

The real session was captured by a mitmproxy intercept of the authenticated `claude` client using Opus 4.8 on 2026-08-10. Prompt segment sizes were measured from actual request bytes; token counts are anchored to the API's cache-creation and cache-read usage accounting. The committed evidence is `real-session-raw.jsonl`, `real-session-segments.jsonl`, `main-thread.json`, and `segments-main.json` in this directory.
